# Dataset validation

## Amrita SLR
Set `AMRITA_DATASET_PATH` to the dataset root. The current adapter detects videos inside first-level class folders and extracts MediaPipe Holistic pose (33×4) plus both hands (21×3 each), 258 values per frame. This differs from some commonly used 134-coordinate configurations; the model uses the dimensions generated by this implementation. Verify that the detected class folders match your dataset before training.

## ISL-CSLRT
Set `ISL_CSLRT_DATASET_PATH` to the directory containing `corpus_csv_files`, `Frames_Sentence_Level`, `Frames_Word_Level`, and `Videos_Sentence_Level`. The inspector reports spreadsheet headers and sample rows. It intentionally does not guess how annotations refer to images/videos. Use that inspection output to build and validate the Dataset 2 adapter before training.

Keep label mappings separate. Split by source video/signer when possible. Never report results from training loss as test accuracy.
